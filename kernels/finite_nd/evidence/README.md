# Evidence map

Author: STARGA Inc.

Root-level receipts capture the integrator's exact CLI/suite/regression and
eight-mutant campaign. Generic CLI results refer to the bound certificate,
not to an automatic project acceptance decision. COMMANDS.md records staging,
compiler and invocation details. The SOURCE/ELF digests are in the associated
.sha256 files; package SHA256SUMS also binds all archived receipts.

independent-review/ is a separate reviewer's frozen MIND probe, 33-case
prelist, exact statement decode, source/rule review, fresh full-suite execution
and 26 mutation-control reruns. Its own SHA256SUMS is verified from that directory.
The duplicated top-level REVIEW.md is the final review text for easy reading.

assembly-attempts/ retains the suite engineer's failed import-layout experiments
and final successful native run. Its manifest is verified from that directory.
The correct source layout is documented in ../tests/BUILD.md. The earlier
manifests are historical records, not current-package checksum lists.

diagnostics/ contains optional external arithmetic cross-checks, explicitly
outside the project proof dependency and acceptance boundary. See DIAGNOSTICS.md.
No ELF binaries, credentials, private RH source or external-language generators
are committed here. The owner-review source bundle can rebuild the programs
with the pinned toolchain; checksums do not replace proof-rule approval.
